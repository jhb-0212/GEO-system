## 评估口径

1. **提交图**：分支 tip 是否为 `main` 祖先；`git cherry` 判断补丁是否已被 main 等价吸收。
2. **实际差异**：从 merge-base 到分支 tip 的文件数、增删行数，以及新增文件是否已存在于 main。
3. **可合并性**：`git merge-tree --write-tree main <branch>` 检查冲突；无本地对象的远端分支用 GitHub Compare API。
4. **内容核对**：对标记为“补丁等价”的分支，再核对 main 是否已有对应实现，避免只看提交图。

- 远端分支删除不可逆性较高；建议先给待删分支打本地或远端 tag，再执行删除。
