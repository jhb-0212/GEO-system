# P5 收口记录（2026-11-23）

对标路线 P5「权限矩阵、审计、导出、E2E、文档、OpenAPI 重生成」的落地记录。分支 `feature/platform-parity-v1`。

## 1. 权限矩阵补齐

`docs/权限矩阵.md` 新增三页与四类操作，全部复用既有能力码，不新增码值（新码需要角色种子与迁移，收益低于成本）：

| 页面 / 操作 | 能力码 | 说明 |
|---|---|---|
| 生成批次（页面） | `content.read` | 与内容审核同门槛 |
| 健康体检（页面） | `stats.read` | 只读统计类 |
| 流量看板（页面） | `stats.read` | 与统计看板同门槛 |
| 生成批次：新建/跑批/审稿 | `content.write` | 仅 editor |
| 生成批次：CSV 导出 | `export.data` | 与线索导出、发布看板导出一致 |
| 流量事件导入 | `monitoring.execute` | 与监测执行同门槛 |

## 2. 审计覆盖核对

| 动作 | 审计 | 落点 |
|---|---|---|
| 建生成批次 | `record_audit` | `api/generation.py` |
| 跑批 | `record_audit` | 同上 |
| 审稿（reviewed 翻转） | `record_audit` | 同上 |
| 批次导出 | `record_export` | 同上，`export_type=generation_batch` |
| 发起体检 | `record_audit` | `api/health_checks.py` |
| 微站创建/发布 | `record_audit` | `api/microsite.py` |
| 线索导出 | `record_export` | `api/leads.py` |
| 发布看板导出 | `record_export` | `api/publish_board.py` |
| 流量导入 | 走 `site_diagnostics` 既有导入审计 | `api/site_diagnostics.py` |

只读接口（列表/详情/汇总）不写审计，避免审计表被浏览行为灌满。

## 3. 导出与打印

- CSV：生成批次导出（`GET .../generation-batches/{id}/export`），列固定、`csv_safety` 处理公式注入、`ensure_sync_export_allowed` 限行数、`record_export` 留痕。
- 打印/PDF：不引第三方库。`kit.css` 末尾加 `@page` + `@media print`，打印时隐藏侧栏、顶栏、工具栏、表单、弹层，面板去阴影、表格去 `max-height/overflow`、`thead` 重复、卡片与行 `break-inside:avoid`，A4、页边距 12mm。
- 入口：顶栏新增「打印/导出」按钮（`Icon name="printer"`），点击触发 `window.print()`；任意工作台页面可直接导出 PDF。
