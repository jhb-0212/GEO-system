# 公开站交付说明（子域首版）

> 状态：首版代码已落地，本地生产构建验证通过；**尚未上线**。默认按子域 `https://geo.gdccai.com` 设计，最终子域、DNS 管理方、证书签发方式和部署主机仍待确认。
> 范围：只做公开站，不改 `www.gdccai.com` 现有官网，不做整站重做。

## 1｜交付范围

公开站与工作台共用现有 `frontend/` Next.js 应用：

- 根路径 `/` 是公开站首页，不再 `redirect("/workbench")`。
- `/login`、`/workbench`、`/internal/*` 仍是内部工作台，公开导航不展示，`robots.txt` 禁止抓取。
- 公开站当前为静态内容，不读取业务数据库，不调用需要 `content.read` 的 `pages` 接口。
- 现有 `www.gdccai.com` 官网保持不动；官网证书、canonical、sitemap 等问题不在本次改动范围内。

## 3｜技术实现

- Next.js 16.4.5 / React 19.3.0，与工作台同一个应用、同一套构建和部署。
- 公开站组件在 `frontend/components/public/`，样式在 `frontend/app/public.css`，全部限定在 `.site-shell` 下，避免影响工作台。
- 公开页面均为服务端组件，无客户端状态；不依赖后端，构建时可静态生成。
- `frontend/app/sitemap.ts` 生成 `/sitemap.xml`，`frontend/app/robots.ts` 生成 `/robots.txt`。
- 根 URL 默认 `https://geo.gdccai.com`，由 `NEXT_PUBLIC_SITE_URL` 覆盖；canonical、Open Graph、sitemap、robots 共用该值。

## 4｜SEO / GEO 项

- 每个公开页面有独立 `<title>`、description、canonical、Open Graph URL。
- 首页输出 `EducationalOrganization` JSON-LD；课程页输出 `Course` JSON-LD；FAQ 输出 `FAQPage`；联系页输出 `ContactPage`；事实页输出 `WebPage` + `ItemList`。
- `sitemap.xml` 包含 7 个公开页面；`robots.txt` 放行公开页，禁止 `/login`、`/workbench`、`/internal/`、`/api/`。
- 登录页与工作台设置 `noindex, nofollow`，不进入公开搜索。
- 公开站不发布未经确认的薪资数字、排名或就业承诺；涉及“保就业/保薪资/保稳定”处均注明“以双方协议为准”。

## 6｜上线前置（尚未完成）

1. **子域确认**：默认 `geo.gdccai.com`；如最终用其他子域，改 `NEXT_PUBLIC_SITE_URL` 后重新构建。
2. **DNS**：新增子域记录，指向部署主机；`www.gdccai.com` 与裸域现状不动。DNS 管理方待确认。
3. **TLS 证书**：为子域签发证书，放入 `deploy/nginx/certs/fullchain.pem` 与 `privkey.pem`；证书方式待确认。
4. **Nginx**：现有 `deploy/nginx/geo.conf` 的 `server_name` 从 `geo.example.com` 改为实际子域；其余反代规则可直接复用。
5. **构建参数**：`NEXT_PUBLIC_SITE_URL=https://geo.gdccai.com`，在 `frontend` 镜像构建时传入；默认值已是该子域。
6. **部署主机**：与前后的 API/工作台同一套 compose，或只把 `frontend` 暴露到子域；具体主机待确认。

## 8｜未做 / 边界

- 不做在线表单：当前没有匿名线索写入端点，避免出现“提交成功但不落库”的假表单；咨询统一走电话和原官网。
- 不接 CMS：内容在 `lib/public/site.ts` 静态维护，改文案后需重新构建；后续拿到官网后台权限或做内容后台时再迁移。
- 不调用 `GET /api/v1/projects/{project_id}/pages`：该接口需要 `content.read`，不是公开只读端点。
- 不处理 `www.gdccai.com` 的证书 CN、canonical、`http://` sitemap、裸域 DNS；这些属于现有官网，需后台权限或运维处理。
- 不承诺就业结果：页面只复述基地公开口径，具体条件以协议为准。
