## 三、边界与后续

- 本清点不删除 `rolled_back` 批次记录：它们是“导入过、已回滚”的审计证据，删除会失去回滚追溯。
- 本清点不自动停用 `seed` / `probe` 账号；生产上线前如需停用，走账号管理流程并记录审计。
- 每次新的历史数据导入后，应重跑本接口；只有 `completed` 且 `delta` 为正的批次才会被计入残留。
- 当前 97 条样本来自真实 API 监测，不是历史本地数据；`evidence_files=0` 属于证据录入缺口（P17/P19），不在本项清点范围内。

## 四、复核命令

```powershell
$base='http://127.0.0.1:8000/api/v1'
$login=Invoke-RestMethod -Method Post -Uri "$base/auth/login" -ContentType 'application/json' -Body (@{username='geo_admin';password='geo-admin-dev'}|ConvertTo-Json)
$h=@{Authorization="Bearer $($login.data.access_token)"}
(Invoke-RestMethod -Uri "$base/system/data-provenance" -Headers $h).data.summary
```
