# 工作台模块折叠（2026-11-17）

## 1｜需求

工作台各页面的模块（面板）太多、太长，希望**每个模块都能收起**，不要一路往下滚。

## 2｜做法：只改一处 `Panel`

工作台 104 个面板全部走 `components/ui.tsx` 的 `Panel`，没有手写 `<section className="panel">`（已核对，0 处）。所以改造 `Panel` 一个组件即可让全部页面生效，调用点零改动。

`Panel` 现在的行为：

1. 在 children 里找**直接子元素**且 className 含 `panel-heading` 的那一块，认定它是标题；
2. 找到标题就在标题右端插入「收起 / 展开」按钮（`chevronDown` ↔ `chevronRight`，带 `aria-expanded`）；
3. 折叠时给面板加 `panel-is-collapsed`，CSS 把 `除标题以外的直接子元素` 设为 `display:none`；
4. 找不到标题的面板（如指标卡、提示卡）不出现按钮，保持原样。

## 3｜为什么这样做

- **不插包裹层**：折叠用 `> :not(.panel-heading){display:none}` 直接作用于原有子元素，DOM 层级不变。这点很关键——样式里有 `.list-panel > .table-scroll`、`.list-panel > .monitor-table` 这类**直接子选择器**，一旦包一层就会全部失效。
- **不卸载内容**：折叠只是 CSS 隐藏，React 组件仍挂载，所以未保存的表单草稿、分页位置、滚动位置都不会丢（折叠再展开不会重置）。
- **状态记忆**：按 `面板 className + 标题 h3 文本` 生成 key 存 localStorage，用 `useSyncExternalStore` 读取（不走「effect 里 setState」，避免首帧错位和 `react-hooks/set-state-in-effect` 告警）。服务端渲染取默认展开，水合后切到真实状态。
- **布局副作用**：网格里的面板默认被拉伸到行高（折叠后仍占 305px）；加 `align-self:start` 与 `min-height:0` 后，折叠面板收缩到标题高度。

## 5｜实测（真实接口模式，geo_admin 只读账号）

| 页面 | 结果 |
|---|---|
| 工作概览 | 8 个 panel 中 4 个有标题 → 4 个折叠按钮；指标卡无按钮（本来就没有标题行） |
| 单个面板（品牌提及趋势） | 展开 321px → 折叠 84px；`aria-expanded=false`；刷新后仍是折叠态（记忆生效） |
| 素材库 | 展开 250px → 折叠 84px，`knowledge-toolbar` / `knowledge-list` 切到 `display:none` |
| 渠道台账 | 展开 729px → 折叠 84px |
| 项目管理（表格面板） | 展开 294px → 折叠 86px；折叠时 `.table-scroll` 仍是 `list-panel` 的**直接子元素**，`td` 左内边距 `23px`、`table` 最小宽度 `850px` 全部保留 |
| 整页效果 | 概览页收起 2 个面板：页面高度 1325 → 1088 |
| 统计看板 / FAQ / 素材 | 各自面板均出现折叠按钮，原有「立即检测」等工具栏按钮位置不变 |
