## 4｜目标与现状差距

1. **首轮 4 个入口**：只差豆包、元宝的 API 入口；DeepSeek、文心已接通。
2. **15 个候选目录**：目录已存在，但官方入口、联网、来源可见、访问限制、最近核验大部分仍是“待核验”；扩展/探测默认 inactive，不参与 24 格。
3. **入口分离**：DeepSeek、文心已有 web_user + api 两条；豆包、元宝目前只有 web_user，API 入口待建。夸克、秘塔、百度AI搜、360纳米AI、微信搜一搜AI、知乎直答、小红书点点目前只有 app_search 占位。
4. **纯应用内检索**：`app_search` 不进入 24 格，单列核验；当前都未接协议。
5. **最近核验日期**：API 入口由 `test-connection` 自动写 `last_verified_at`；web_user / app_search 没有测试连接，当前只能在本文档记录日期。若要在系统内结构化，需要新增手动核验端点或字段，属于后续改动。
6. **引用记录**：元宝 SearchPro 能返回 `Pages` 与 URL；DeepSeek、文心、豆包的对话 API 不返回 citation，不能生成“引用网页/渠道”数据。
