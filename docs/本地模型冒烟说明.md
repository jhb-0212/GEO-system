# 本地模型冒烟说明（仅开发/链路验证）

> 责任人：C。适用：C 侧内部验证。**本地模型不是正式 4 平台之一，不能作为 GEO 业务基线。**

## 一、用途

本地 Ollama / vLLM / LM Studio 提供 OpenAI 兼容接口时，用 `backend/scripts/local_llm_smoke.py` 跑 6 道技术基线题，验证：

- `LocalLLMAdapter` 能发请求、拿回答、归一成 `AnswerPayload`；
- `execute_task` 的状态机、样本抢占、hit/miss 落库正常；
- `geo_overview` 能读到有效回答、失败率、题库覆盖等指标；
- 失败码 `access_blocked` / `timeout` / `rate_limited` 能按真实响应归类。

它**不验证**：

- DeepSeek / 豆包 / 百度文心 / 腾讯元宝的真实检索结果；
- 这些平台的引用来源、SOV、引用份额；
- 24 格（6 题 × 4 平台）业务基线。

本地模型默认没有联网搜索/引用，`citation_share` 仍为 `null`；`mention_rate` 只说明本地模型回答里有没有出现项目名，不是平台 GEO 表现。

## 二、前置条件

- Docker Desktop 已启动，`geo-postgres` 正常（宿主端口 5433）；
- 本机 Ollama 已启动，且模型已拉取；
- 仓库根目录有 `.env`，`DATABASE_URL` 指向 `geo` 库；
- 后端 venv 已装依赖（含 `httpx`、`psycopg`）。

本机已验证的模型：

```text
qwen2.5:7b
deepseek-r1:7b
gemma4:e4b
```

## 三、运行

在仓库根目录执行：

```powershell
.\backend\.venv\Scripts\python.exe backend\scripts\local_llm_smoke.py --keep --json
```

默认：

- 临时库 `geo_local_smoke`（必须以 `_smoke` 结尾）；
- 启动先 DROP/CREATE，跑 `alembic upgrade head` + `seed.py --technical-baseline`；
- 建 1 个本地平台入口（`local-ollama-smoke`），6 题 × 1 平台 = 6 个任务；
- 跑完默认 DROP；`--keep` 保留临时库供查样本。

指定模型/地址：

```powershell
.\backend\.venv\Scripts\python.exe backend\scripts\local_llm_smoke.py `
  --base-url http://127.0.0.1:11434/v1 `
  --model qwen2.5:7b
```

Worker 跑在 Docker 容器里时，`127.0.0.1` 是容器自己，必须改成：

```text
http://host.docker.internal:11434/v1
```

## 四、已跑结果（2026-11-13，qwen2.5:7b）

```text
题目 6 / 任务 6
有效回答 6
失败样本 0
mention_rate 0.0
citation_share null
prompt_coverage 1.0
failure_rate 0.0
freshness_hours 0.0
fresh_24h_rate 1.0
```

结论：采集链、解析、状态机、指标读取均走通；`mention_rate=0` 说明本地 qwen 没有识别“广州基地”，属于预期，不代表 4 平台真实表现；`citation_share=null` 符合“本地模型无引用来源”的边界。

## 五、边界与清理

- 不写正式 `geo` 库；脚本拒绝操作库名不以 `_smoke` 结尾的数据库；
- 不把 `local-ollama-smoke` 写进正式 `ai_engines` 目录；
- 不把本地模型结果混入 24 格基线或报告；
- `--keep` 产生的库确认后可手工删除：

```powershell
# 用 psql 或 DBeaver 连接 postgres 库后执行
DROP DATABASE IF EXISTS geo_local_smoke WITH (FORCE);
```
