## 2｜发布闭环：登记账号到回执结案已走通

### 代码

- 新增 `PublishAccountCreate`（`channel_id`、`account_name`、`credential_ref`、`notes`）；
- 新增 `POST /api/v1/projects/{project_id}/publish/accounts`，权限 `publish.execute`；
- 校验渠道存在且 active；同渠道 `account_name` 唯一，冲突 409 `publish_account_exists`；写审计 `publish.account_create`；返回 `id/account_name/channel_id/is_active/notes`；
- schema 从 `app/schemas/__init__.py` 导出；前端发布页在 `!canExecute` 时增加说明“可查看、无执行权限，登记账号/创建任务需运营编辑”，避免项目管理员误以为页面坏了。

### 真实库链路

使用 `geo_editor` / `geo_reviewer` 在 `gz-base`（`154640d4-6356-4a1c-8bde-2d511cfb06cd`）走通：

1. `POST /publish/accounts`：渠道 36氪（`7cead84d-ea30-4edc-9e61-4662bed1308a`），账号“36氪运营账号” → 201，账号 id `d479978c-c233-4423-9ee2-1098f832b3ed`；
2. 同账号重复登记 → 409 `publish_account_exists`；
3. `geo_admin`（项目管理员，无 `publish.execute`）登记 → 403；
4. `POST /contents`（`kind=channel`）→ 201，内容 id `13132a54-07ff-4a59-b8f3-afe81629fed8`；
5. `POST /contents/{item_id}/versions` → 201，版本 id `09ad3e29-5968-41c1-97b2-64dd54a3c56b`；
6. `POST /content-versions/{version_id}/submit` → 200；
7. `POST /content-versions/{version_id}/review`（`geo_reviewer`，`approved`）→ 200；
8. `POST /publish/tasks` → 201，任务 id `2fef1d7f-1356-4d90-8ef5-b025012c2bdc`，状态 `pending`；
9. `POST /publish/tasks/{task_id}/attempts` → 201，`task_status=publishing`；
10. `POST /publish/tasks/{task_id}/receipts`（`published_url=https://36kr.com/p/geo-live-smoke`）→ 200，`status=published`，回执 id `439ad660-2bc8-43f5-bd8b-d05eec8e4bcb`。

这条链路证明“运营建草稿 → 提交 → 审核通过 → 建发布账号 → 建任务 → 记录发出 → 回填 URL 结案”已经闭合，不再只是页面按钮。

## 3｜前端生产部署：3100 不再返回 `__next_error__`

### 修复

- 根因是 `frontend/app/workbench/layout.tsx` 在无 token 时 `redirect("/login")`，被 Next 16 `cacheComponents/partialPrefetching` 的 instant 校验当成渲染错误，日志为 `NEXT_REDIRECT;replace;/login;307`；
- 改为不再抛 redirect：无 token、认证服务不可用、token 过期、403 都返回内联 `LoginGate` / `access-denied` 页面（带“前往登录/重新登录”链接）。

### 构建与实测

- `pnpm lint` 通过；
- `pnpm build` 通过，19 个路由正常生成，`/workbench` 为动态 `ƒ`；
