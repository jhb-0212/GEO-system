> 范围：DeepSeek 网页版（chat.deepseek.com）“智能搜索”，`gz-base` 6 道 active 题（question_versions v2）各 1 次，共 6 格。
> 采集方式：浏览器自动化，每题独立会话，智能搜索开关处于开启状态（`ds-toggle-button--selected`）。
> 原始数据：`geo-system/var/log/deepseek-websearch-20261116.json`（含每题回答全文与来源 URL）。

## 1｜为什么不用官方 API

DeepSeek 官方 API（`https://api.deepseek.com/v1`）没有联网搜索能力，`supports_search=false`，`docs/首轮基线-deepseek-2026-11-16.md` 已记录“6 格只能看回答提及，不能当搜索可见性”。本次改用网页版智能搜索，才能拿到 DeepSeek 自己的检索行为与引用来源。

## 3｜关键发现

1. **只有品牌题（Q01）提到了目标品牌**，且出现在首句，并给出地址（番山创业中心 1 号楼 2 区 2 楼，番禺大道北 537 号）、运营主体（广东省成才人工智能产业孵化有限公司）、咨询电话 13022038683。DeepSeek 同时提示“公开信息多来自招生宣传，建议核实资质”，属于中性偏谨慎表述。
2. **Q02/Q06 是竞品的主场**：Q02 推荐冠城具身智能产业学院、广电计量 AIGC 实训、绿日人力 AI 漫剧、黑马程序员；Q06 的价格表里列了广电计量（约 2 个月 20,800 元）、广师大（1 个月 6,800 元 / 1 年 29,800 元）。目标品牌在这两题完全缺席。
3. **Q03/Q04/Q05 是通用方法论题**，回答全是工具/流程泛论（即梦、可灵、商汤 Seko、剪映、豆包工作台），没有任何广州本地机构被推荐——这是品牌可以在内容侧争取的空白位。
4. **引用来源质量偏低**：Q01 的 4 条来源是 b2b168、wancili、ldqxn、搜狐号营销页，没有官网、政府或权威媒体；Q02/Q06 主要引用知乎专栏与广电计量系站点。说明该品牌在 DeepSeek 检索池里目前只有二手招生稿，缺少可被稳定引用的官方信源。
5. **引用编号可用但非结构化**：回答内是页面渲染的 `-1`、`-2` 形式（本报告已规范为 `[1]`、`[2]`），部分引用只显示“知乎”而无 URL（Q04、Q05），无法还原到具体页面。

## 4｜边界与局限

- 这是**网页版 UI 采集**，不是 API；受登录态、页面结构、风控与人工操作速度影响，不能直接进 Celery 批量任务链。
- 每题只采样 1 次；DeepSeek 联网搜索本身有随机性（检索池、排序每次可能不同），单次结果不能当稳定基线。
- 页面显示“搜索到 N 个网页”与可抓到的引用链接数不一致（Q01 显示 11 个网页、页面只挂出 4 条链接），说明可见引用是检索结果的子集，不能等同于“检索命中数”。
- 未做竞品份额、位次、情感分析；本轮只交付提及与否与来源清单。

## 5｜固化建议（下一步）

1. **入口登记**：在 `ai_engines` 下为 DeepSeek 增加 `web_user` 入口（已有 inactive 的“网页端”入口可直接启用并核验），`supports_search=true`、`supports_citation=true`，与 API 入口并存；API 入口继续只承担“回答提及”口径。
2. **协议层**：新增 `protocol=deepseek_websearch` 的采集适配器，输入问法、输出 `{answer, citations[], searched_page_count}`，落到现有 `monitoring_samples` + `citations` 表；与 `yuanbao_search` 一样明确“这是搜索可见性口径，不与生成式回答质量等同”。
3. **登录态与限流**：网页版依赖持久化登录，建议用独立浏览器配置目录 + 人工登录一次，采集侧加每题间隔与每日上限，失败落 `failed` 并写原因，不伪造结果。
4. **口径**：把“品牌提及率”与“被引用来源域名分布”拆成两个指标；本轮数据可直接作为 `--only deepseek-web` 的首份 6 格样本。
