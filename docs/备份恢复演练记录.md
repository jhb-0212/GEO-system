## 四、生产建议

| 项 | 建议 |
| --- | --- |
| 备份频率 | 每日全量（`pg_dump -Fc`）+ 每小时 WAL 归档；重大操作（导入、批量发布）前手动补一次 |
| 保留策略 | 本地 7 份滚动，异地对象存储保留 30 天，月度归档长期保留 |
| RPO / RTO | RPO ≤ 1 小时（取决于归档频率），RTO ≤ 30 分钟（单机 + 备份还原） |
| 恢复演练 | 每月一次，按本脚本还原到临时库比对，记录放入本文件 |
| 对象存储 | 证据文件开启版本控制与生命周期保护，删除操作需二次确认 |
| 备份校验 | 每次备份后自动跑 `pg_restore --list`，失败立即告警 |
| 密钥 | 备份文件加密存放，不与数据库同机；恢复权限仅限 C 与运维 |

## 五、未覆盖项（需在生产机补做）

1. 生产宿主机磁盘容量与备份文件异地同步仍需在部署机核实（容器内 `/backups` 挂载已在第六节验证可写）。
2. WAL 归档与时间点恢复（PITR）：当前方案只用逻辑备份，未配置 PITR，如需更低 RPO 需加 `archive_mode` 与归档目录。
3. 备份文件加密存放与恢复权限的实际链路。
