
### 15.48 网页端采集降频与限流不重试（2026-11-17）

- 背景：DeepSeek 网页版采集依赖浏览器登录态，高频或连续批量提问会触发平台风控，账号可能被禁言；原配置为全局 6 次/分钟 + 采集桥最小间隔 15s，仍偏激进；
- 新增 `monitoring_websearch_rate_limit_per_minute`（默认 2 次/分钟），`EngineRateLimiter` 在引擎码含 `websearch` 时走该上限，普通 API 引擎仍按全局 6 次/分钟；显式传入 `limit_per_minute` 时保持原有行为（测试用）；
- `deepseek_websearch_adapter` 收到桥的 429 时改落 `rate_limited` 且 `retryable=False`，不再由 Worker 自动重试，避免连续失败加重风控；

- 定向测试 25 passed（新增：网页端 2 次/分钟上限独立生效、429 不重试）；
- 边界：限速是应用侧护栏，不能替代人工判断；同一问题短时间重复采集、含指令式/敏感措辞的提问仍应人工避免。
### 15.49 网页端采集冷却、日额度与重试收敛（2026-11-17）
