# FAQ 官网落位与可摘取事实清单（2026-11-17）

> 背景：GEO 不做公开站，对外页面归公司官网 `www.gdccai.com`。本文件不新建 `/faq/` 栏目，而是把 FAQ 内容落进官网**已有**页面，并列出官网当前缺的「AI 能直接摘取的事实」。
>
> 全部内容只使用官网当期已发布的事实，未标价、未核实的项一律写「待确认」，不编造数字。

## 一、三句话结论

1. **系统里那 3 条 FAQ 是占位符**（正文为「【占位待运营确认】请在此填写…」），不是内容，需要按官网事实起草。
2. **官网全站没有具体学费、没有开班日期、没有到校路线**——这三项是「多少钱 / 什么时候开 / 怎么过去」最常被问的问题，AI 拿不到就必然转去引第三方页面（当前 37 条引用里第三方占 100%、官网 0 条，原因正在这里）。
3. **技术面缺三样**：全站无 `canonical`、4 个主要页面无 `h1`、结构化数据只有一条 `WebSite`（没有 `Organization` / `FAQPage` / `Course`）。

三条要点：

- 首页是权重最高的入口，**没有 h1**，标题信息全在 `<title>` 里，AI 抓正文时缺一个明确的主题句；
- `/about/` 有**两个 h1**，主题重复；
- 全站共用一条 `WebSite` 结构化数据，页面级实体（机构、课程、问答）一个都没声明。

### 3.2 报名 —— 落位两门课程的详情页（`show-98519` / `show-98518` 各自的「报名与费用」段）

**Q：报名需要什么条件，流程怎么走？**

**A：** 两个班型条件不同：

## 四、为什么不新建 `/faq/`

| 理由 | 说明 |
| --- | --- |
| 新页零权重 | 新建页面要等收录，官网现有页面已经在被检索的池子里（虽本轮未被引用，但已在索引中） |
| AI 摘取偏好页内问答 | 「问题式小标题 + 紧随其后的答案 + 数字」比独立 FAQ 页更容易被原文摘用 |
| 避免再开一份真源 | 官网已有 `/contact/`、两个课程详情页承载了这些事实，独立 FAQ 页必然与它们漂移 |

## 六、可摘取事实缺口清单（按对 AI 回答的影响排序）

| 优先级 | 缺什么 | 现状与影响 |
| --- | --- | --- |
| **P0** | 学费金额或区间 | 全站只写「顾问出具方案」。AI 回答「学费多少」时官网无数字可用 → 必然引第三方 |
| **P0** | 开班日期 / 最近一期时间 | 官网只有「约 8 周 / 近 3 个月」的学制，没有「下一期几号开」 |
| **P0** | 到校路线（地铁/公交/停车） | `/contact/` 只有地址与电话，无交通方式 |
| **P1** | 报名流程的步骤化表述 | 条件与流程散落在课程页段落里，没有「第1步…第5步」这种可被整段摘取的形态 |
| **P1** | 两班型对比表 | 课时、人群、产出分散在两页，AI 做「哪个适合我」的比较时没有对照 |
| **P1** | 住宿与设备租赁的具体标准 | 全站只写「另有标准」，没有价格或条件 |
| **P2** | 就业结果数据 | 现有「往期约九成七本科生、九成五为毕业2–5年社会人员」是学员画像，不是就业率/去向企业名单 |
| **P2** | 资质与证照 | 只有 `粤ICP备2026164458号`（备案），无营业执照名称、办学许可等可核验信息 |
| **P2** | 「符合条件未按约定就业可全额退款」的条件细则 | 「符合条件」具体指什么没有写，属高风险承诺，AI 引用后容易引发争议 |
| **P3** | 首页补 `h1` | 首页当前 0 个 h1 |
| **P3** | 全站补 `canonical` | 8 个主要页面全部缺失 |
| **P3** | `/about/` 两个 h1 收敛为一个 | 主题重复 |
| **P3** | 页面级结构化数据 | 补 `Organization`、`FAQPage`、`Course`（见第五节） |

## 七、改完怎么验收（不要靠感觉）

1. **回填登记**：官网改版后跑 `backend/scripts/import_public_pages.py --update`，让 `public_pages` 里 69 条记录的标题/URL/类型与实际一致；新增页面按 `PATCH /api/v1/projects/{project_id}/pages` 补登记。
2. **跑两轮采集**：用已通的 `deepseek_websearch` 链路，改版前一轮、改版后一轮，同一批问题。
3. **看的指标（当前基线）**：

| 指标 | 现在 | 突破标志 |
| --- | --- | --- |
| `citation_share` | 0.0（37 条引用 0 条来自 gdccai.com） | 引用里出现 `gdccai.com` 域名即算突破 |
| `brand_identified_rate` | 0.1667（1/6） | 「问地址/电话」类答案出现官网口径 |
| `brand_mention_rate` | 0.0（0/6） | 答案开始复述品牌名 |

4. **判读纪律**：只改内容、不跑采集，等于没验证。若改完 `citation_share` 仍是 0，说明问题不在内容密度而在索引收录（届时查必应/百度收录与 robots），不要继续加文案。

## 八、边界（本文件没做什么）

- **没有改官网**：官网不归本系统部署，任何改动需由官网侧执行；
- **没有动 FAQ 表数据**：3 条仍是草稿占位状态，等 P0 事实（学费、开班、路线）由业务方确认后再定稿上架；
- **没有编造任何数字**：学费、地铁站、就业率、住宿价格官网均无，文件中一律标「待确认」；
- **没有把「月薪 8K–25K+」写进 JSON-LD**：那是对外承诺性表述，是否继续公开由业务决定。
