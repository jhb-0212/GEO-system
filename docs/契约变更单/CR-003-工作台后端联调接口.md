## 变更与原因

| 能力 | 路径或字段 | 原因 |
| --- | --- | --- |
| 浏览器登录 | `POST /api/v1/auth/login`、`GET /api/v1/auth/me`、`POST /api/v1/auth/password` | 代替开发令牌，让工作台取得真实身份和项目权限；改密使旧令牌失效 |
| 监测复核 | `GET /api/v1/projects/{project_id}/monitoring/samples`、`GET /samples/{sample_id}`、`POST /samples/{sample_id}/manual-review` | 回看原始回答、失败原因及引用，人工判定只允许待复核样本归入 hit/miss |
| 引用归类 | `GET /api/v1/projects/{project_id}/citations`、`GET /citations/unknown-domains`、`PATCH /citations/{citation_id}` | 按项目查询引用与未知域名，记录人工确认或驳回 |
| 审核闭环 | `GET /api/v1/projects/{project_id}/content-versions`、`POST /content-versions/{version_id}/submit`、`GET /content-versions/{version_id}/reviews` | 提交、待审列表、审核历史形成闭环；只有已提交版本可审核 |
| 监测任务列表 | 原 `GET /monitoring/tasks` 增加问题、引擎名称及时间字段 | 前端列表直接展示关联信息，避免逐条补查 |
| 统计看板 | `GET /api/v1/projects/{project_id}/stats/overview`、`by-engine`、`by-question`、`trend`、`task-distribution` | 复用现有指标口径与样本数据，为工作台卡片和趋势提供接口 |
| 项目审计 | `GET /api/v1/projects/{project_id}/audit-logs` | 项目内活动记录按 `project_id` 隔离 |

完整请求、响应字段以同分支 `docs/openapi.json` 为准。业务数据仍通过现有权限码授权；新接口使用统一成功、分页和错误信封。

B1 以本分支实现为准：`login` 返回令牌及 `expires_in`，`me` 返回活跃项目、角色及能力码；认证错误包含 `invalid_credentials`、`token_stale`。`feat/b1-auth-login` 的 login/me 模板未合入本分支。

## 数据库与兼容性

- 新迁移 `a84f6e1b2c3d` 给 `users` 增加 `token_version NOT NULL DEFAULT 0`。JWT 增加整数 `tv`；没有该字段的旧令牌返回 `401 token_stale`，用户需重新登录。
- 迁移链已接在远端现有引擎入口迁移 `13d970f42b3c` 后，避免形成多个 Alembic head。
- 新迁移 `b72c8d9e0f11` 给 `content_versions` 增加可空的 `submitted_by`、`submitted_at`，保留存量版本数据。
- 只有草稿版本正文可编辑；提交过的版本（含驳回版本）正文不可覆盖，修改内容须创建新版本。待审核、审核决定和正文哈希保持一致。
- 不修改已有表的主键、外键或项目隔离规则。两份迁移需按仓库约定交 C 评审后才能合入。
