## 一、问题

1. Worker 是否活着没有任何可探测信号：容器 `restart: always` 只保证进程在，进程卡死、broker 断连时外部监控看不到。
2. 队列积压没有暴露口：任务投进去没人消费时，只能人工进 Redis 看 `LLEN`。
3. 备份失败只有控制台输出；无人值守时失败不会被发现。

## 二、变更项

| # | 变更 | 落地位置 |
| --- | --- | --- |
| 1 | `GET /health/worker`：读 `geo:worker:heartbeat:*` 键；无键 → 503 `none`，全部超时 → 503 `stale`，Redis 不可用 → 503 `unavailable`，否则 200 | `backend/app/api/health.py` |
| 2 | `GET /health/queue`：读 broker 默认队列（`celery`）的 `LLEN`；超过 `queue_backlog_threshold`（默认 100）→ 503，broker 不可用 → 503 | `backend/app/api/health.py` |
| 3 | 响应模型：`HealthWorkerData`、`WorkerHeartbeatData`、`HealthQueueData` | `backend/app/api/responses.py` |
| 4 | Worker 心跳写入：`worker_ready` 信号起守护线程，每 30s 写 `geo:worker:heartbeat:<hostname>:<pid>`，TTL 90s；Redis 异常只丢一次心跳，不影响任务 | `backend/app/worker.py` |
| 5 | 容器健康检查：`python scripts/worker_healthcheck.py`，任一新鲜心跳退出 0，否则 1 | `backend/scripts/worker_healthcheck.py`、`deploy/docker-compose.prod.yml`（worker 服务） |
| 6 | 备份失败告警：`backup_db.ps1` 新增 `-AlertWebhook`（或环境变量 `BACKUP_ALERT_WEBHOOK`），失败 POST JSON；未配置只写日志；无论是否推送成功都以退出码 1 结束 | `deploy/scripts/backup_db.ps1` |
| 7 | 配置项：`queue_backlog_threshold=100`、`celery_default_queue="celery"` | `backend/app/core/config.py`、`.env.example` |
| 8 | 文字契约与交付清单同步：`docs/API契约.md` 探活行补入两路径；`docs/交付包清单.md` 第 6 项登记；`deploy/.env.prod.example` 补 `QUEUE_BACKLOG_THRESHOLD` / `CELERY_DEFAULT_QUEUE` / `LOG_LEVEL` / `TASK_ALERT_WEBHOOK` | `docs/API契约.md`、`docs/交付包清单.md`、`deploy/.env.prod.example` |

## 三、兼容性影响

- 纯加法：两条路径都在 `/health` 区，沿用既有"健康检查不鉴权"约定，不进入 `/api/v1` 业务前缀。
- 计数变化：路径 20 → 22，操作 24 → 26，schema 57 → 60，`docs/openapi.json` 指纹由 `772769CF…` 变为 `AA2662AE…`。
- 无表结构、无迁移、无权限码、无错误码变化。

## 四、已知边界（写进验收口径，不当作已解决）

1. `/health/queue` 只统计 broker 里**待消费**（ready）条数，不含正在执行与 unacked 的消息；积压口径以 ready 为准。
2. 只覆盖默认队列；后续若拆分多队列，需要按队列分别暴露。
3. 阈值 100 是保守默认值，压测后应按实际吞吐调整，写进生产告警配置。
4. 心跳 TTL 90s、判定超时 120s（TTL + 30s）；worker 进程被 `SIGKILL` 后最长约 2 分钟才判 stale。

## 五、复核方式

```bash
# 1. 起 worker 后看键
docker exec geo-redis redis-cli -n 0 --scan --pattern "geo:worker:heartbeat:*"
# 2. 探针
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8000/health/worker
curl -s http://localhost:8000/health/queue
# 3. 容器健康
docker inspect --format "{{.State.Health.Status}}" geo-prod-worker-1
```
