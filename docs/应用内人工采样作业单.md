## 一、怎么做

1. 进入工作台“样本与引用 → 新增手测样本”。
2. 在“监测任务”里按题目 + 平台选择本轮任务；任务编号是本作业单的 `任务 ID`，下拉里显示为 `Qxx · 平台 · #1 · 待执行`。
3. **逐题新开对话**：每题都必须新开会话，不能复用上一题；勾选“本题已新开对话，未复用上一题会话”后才可保存。
4. 记录**联网模式**：按实际操作选择 `联网开启（search_on）` 或 `联网关闭（search_off）`，不默认沿用上一题。

6. 品牌提及/可识别可保留自动判定；人工确认后点“保存手测样本”，该任务会从 `pending` 转为 `done`。
7. **未能采样时单独登记失败**：登录阻断、超时、访问阻断、验证码、限流等情况，在“本次未能采样”选择对应原因，再点“标记本次采样失败”；任务转 `failed`，失败样本单独进入失败分桶，不进入有效回答分母，也不按有效未命中计算。
8. 不要点“触发采样/执行”：应用内入口没有自动适配器，接口会返回 409 `manual_entry_auto_execute`。
9. 42 条全部 `done` 或 `failed` 后，轮次才可完成；中途不要启用这 7 条入口，否则会被自动任务选中并失败。
