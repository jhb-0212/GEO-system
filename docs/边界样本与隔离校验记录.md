### 1.4 本轮修掉的三个脚本缺陷

| 缺陷 | 修复前表现 | 修复 |
| --- | --- | --- |
| dry-run 与正式导入口径不一致 | 同文件重复在 dry-run 中未计 skipped（dry-run 不写 session，查重看不到前一行）；试跑 `questions imported=103`，正式导入会变成 101 | 每个表增加批次内 `seen` 键集合，试跑与正式导入走同一套去重判断 |
| 超长字段无校验 | 超长 code/title/name/姓名未计 failed，正式导入会在 flush/commit 撞字段长度，整批回滚 | 按模型上限预校验（questions code 32/title 255、channels code 64/name 128、leads 姓名/手机/微信 64、课程 128），超长行计入 failed 并写明长度 |
| 线索去重按 AND、无联系方式直接入库 | 同手机不同微信、同微信不同手机被当成新线索；手机微信都空的行每次重跑都重复入库 | 改为手机号**或**微信号任一命中即 skipped；两者都空计 failed（无法去重），要求业务补联系方式 |
