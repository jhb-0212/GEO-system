## 2. 数据模型与迁移

- `project_id`、`question`、`answer`、`status`（`draft/published/unpublished`）、`sort_order`、`created_by`、时间戳；

## 3. 接口

### 3.1 FAQ

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/v1/projects/{project_id}/faqs` | `content.read` |
| POST | `/api/v1/projects/{project_id}/faqs` | `content.write` |
| PATCH | `/api/v1/projects/{project_id}/faqs/{faq_id}` | `content.write` |
| GET | `/api/v1/public/projects/{project_code}/faqs` | 无（仅 `published`） |

### 3.2 素材

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/v1/projects/{project_id}/materials` | `content.read` |
| POST | `/api/v1/projects/{project_id}/materials` | `content.write` |
| PATCH | `/api/v1/projects/{project_id}/materials/{material_id}` | `content.write` |
| GET | `/api/v1/projects/{project_id}/materials/{material_id}/download` | `content.read` |

上传约束：单文件 20MB；允许 `.png/.jpg/.jpeg/.webp/.gif/.pdf/.doc/.docx/.txt/.md/.csv/.zip`；写 `material.upload` / `material.download` 审计。

### 3.3 线索

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| PATCH | `/api/v1/projects/{project_id}/leads/{lead_id}` | `lead.write` |
| GET | `/api/v1/projects/{project_id}/leads/export` | `export.data` |

`PATCH` 只允许 `enrollment_status`、`note`、`owner_id`，不改归因字段；导出写 `action=export, export_type=leads` 审计，超同步行数上限返回 400。

## 4. 发布工作台

当前定位仍是**手动发布台账**，不是自动发布器：

1. 选已审批渠道稿版本 + 发布账号，建任务；
2. 任务详情展示标题、正文、hash，可“复制正文”；
3. 渠道配置 `publish_url` 时“打开发布后台”，配置 `login_url` 时“打开登录页”；没有配置时回退到 `https://{primary_domain}`；
4. 人工在平台发布后，回工作台记录 attempt、回填真实 URL、必要时 verify。

`PublishMode.api/authorized` 仍未实现；自动发布必须指定具体平台、接入 API 或浏览器登录态，并处理验证码、限流、幂等和外部任务 ID。
