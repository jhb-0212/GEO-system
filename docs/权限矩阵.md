# 工作台权限矩阵

> 日期：2026-11-18  
> 事实源：后端路由能力门禁 + 前端导航元数据  
> 相关方案：`docs/工作台页面可见性与权限分级方案.md`

## 1. 角色定义

| 角色码 | 定位 | 关键能力 |
|---|---|---|
| `sys_admin` | 系统管理员 | `project.create`、`engine.manage`；不默认拥有项目业务数据权限 |
| `project_admin` | 项目管理员 | 管本项目成员；全部项目读能力；审核、渠道/竞品/品牌/指标写；`engine.verify`、`export.data`、`audit.read`、预算查看/提交/审批；可确认项目资料与优先级 |
| `editor` | 运营/编辑 | 题库、监测执行、内容写、发布执行、渠道/竞品/品牌/指标写；`engine.verify`、`export.data`、预算查看/提交 |
| `reviewer` | 审核 | 内容审核、证据复核、统计/审计只读、预算查看/审批；不改正文、不发布 |
| `viewer` | 只读 | 全部项目读能力 + `export.data`；所有写操作拒绝，无预算权限 |
| `lead_ops` | 招生/客服 | 只能读写本项目线索，无预算权限 |

## 2. 页面可见性

`Y` = 可见；`-` = 隐藏。真实接口模式下，隐藏页不会出现在导航；URL 带旧 `section` 时回落到工作概览。

| 页面 | 页面门槛 | sys_admin | project_admin | editor | reviewer | viewer | lead_ops |
|---|---|---|---|---|---|---|---|
| 工作概览 | 已登录 | Y | Y | Y | Y | Y | Y |
| 项目管理 | 已登录 | Y | Y | Y | Y | Y | Y |
| 监测任务 | `monitoring.read` | - | Y | Y | Y | Y | - |
| 竞品台账 | `monitoring.read` | - | Y | Y | Y | Y | - |
| 品牌口径 | `monitoring.read` | - | Y | Y | Y | Y | - |
| 内部排障 | `monitoring.execute` 或 `project.member.manage` | - | Y | Y | - | - | - |
| 题库与目标词 | `question.read` | - | Y | Y | Y | Y | - |
| 样本与引用 | `monitoring.read` | - | Y | Y | Y | Y | - |
| 内容计划 | `content.read` | - | Y | Y | Y | Y | - |
| 内容发布 | `publish.read` | - | Y | Y | - | Y | - |
| 渠道台账 | `channel.read` | - | Y | Y | - | Y | - |
| 媒体报价 | `content.read` | - | Y | Y | Y | Y | - |

| 统计看板 | `stats.read` | - | Y | Y | Y | Y | - |
| 指标口径 | `stats.read` | - | Y | Y | Y | Y | - |
| 内容审核 | `content.read` | - | Y | Y | Y | Y | - |
| 线索管理 | `lead.read` 且 `leadAccess` 非 `forbidden` | - | Y | - | - | Y | Y |
| FAQ 编辑 | `content.read` | - | Y | Y | Y | Y | - |
| 素材管理 | `content.read` | - | Y | Y | Y | Y | - |
| 操作日志 | `audit.read` | - | Y | - | Y | - | - |
| AI 平台入口 | 系统管理员，或任一项目 `engine.verify` | Y | Y | Y | - | - | - |
| 成员管理 | `project.member.manage` | - | Y | - | - | - | - |
| 组件规范 | 已登录 | Y | Y | Y | Y | Y | Y |

说明：

- `sys_admin` 不自动获得项目业务页面；需要项目数据时按项目 `viewer` 单独加入。
- `AI 平台入口` 的全局可见性与后端“任一项目持有 `engine.verify`”一致。
- `leadAccess=forbidden` 时不展示线索菜单，不再用“无权限”占位。

## 4. 后端代表接口

| 接口 | 门禁 | 允许角色 | 备注 |
|---|---|---|---|
| `GET /api/v1/engines` | 系统管理员或任一项目 `engine.verify` | `sys_admin`、`project_admin`、`editor` | `viewer`/`reviewer`/`lead_ops` 403 |
| `GET /api/v1/engines/{id}/entries` | 同上 | 同上 | 非系统管理员裁剪 API 入口 `entry_url` / `credential_ref` |
| `POST /api/v1/engines/{id}/entries` | `engine.manage` | `sys_admin` | 创建/更新/测试均同 |
| `GET /api/v1/projects/{id}/monitoring/diagnostics` | `monitoring.execute` 或 `project.member.manage` | `editor`、`project_admin` | `viewer`/`reviewer`/`lead_ops` 403 |
| `GET /api/v1/projects/{id}/monitoring/traces/{trace_id}` | 同上 | `editor`、`project_admin` | 同上 |
| `GET /api/v1/projects/{id}/leads` | `lead.read` | `project_admin`、`viewer`、`lead_ops` | `editor`/`reviewer` 403 |
| `GET /api/v1/projects/{id}/members` | `project.member.manage` | `project_admin` | 其他角色 403 |
| `GET /api/v1/projects/{id}/audit-logs` | `audit.read` | `project_admin`、`reviewer` | 其他角色 403 |
| `POST /api/v1/projects/{id}/confirm` | `project.member.manage` | `project_admin` | 系统管理员无成员身份时不能越过项目边界 |
| `GET /api/v1/projects/{id}/budget-approvals` | `budget.read` | `project_admin`、`editor`、`reviewer` | `viewer`/`lead_ops`/`sys_admin` 403 |
| `POST /api/v1/projects/{id}/budget-approvals` | `budget.write` | `project_admin`、`editor` | 只允许提交 `pending` 申请；项目内无除提交人外的有效 `budget.approve` 持有人（项目成员与账号均有效）时返回 400 `budget_approver_required` |
| `POST /api/v1/projects/{id}/budget-approvals/{budget_id}/review` | `budget.approve` | `project_admin`、`reviewer` | 仅 `pending` 可审批；驳回必须写原因；编辑不能自批 |

## 5. 字段级规则

| 字段 | 系统管理员 | 项目管理员 / 运营（`engine.verify`） | 其他角色 |
|---|---|---|---|
| API 入口 `entry_url` | 可见 | 隐藏 | 页面不可见 |
| API 入口 `credential_ref` | 可见 | 隐藏 | 页面不可见 |
| 人工核验入口 `entry_url` | 可见 | 可见 | 页面不可见 |
| `credential_configured` | 可见 | 可见（只显示配置状态） | 页面不可见 |
| `config_redacted` | `false` | `true` | 页面不可见 |
| 诊断失败码 / trace | 不可见（无项目权限时） | 可见 | 页面不可见 |

线索联系方式：

- `lead_ops`（`lead.write`）与 `project_admin`：列表和 CSV 导出均返回完整手机号/微信。
- `viewer`：列表和 CSV 导出均脱敏，例如手机号 `138****0002`、微信 `wx****an`。

## 7. 本轮已补齐与剩余项

本轮已补齐：

- `leads.reported_ai_product` / `is_valid` 的 schema、创建/更新逻辑、列表字段、CSV 导出与前端表单/列。
- `project_admin` 的“确认项目资料 + 调整优先级（1–5）”动作，落 `business_confirmed_at` / `business_confirmed_by` 并写审计。
- 四类预算审批实体 `budget_approvals` 与页面，按 `budget.read` / `budget.write` / `budget.approve` 分级。

剩余项：

- 浏览器只读 E2E 已覆盖 5 个真实账号（`geo_admin`、`geo_editor`、`geo_reviewer`、`geo_viewer`、`geo_lead_ops`），共 10 项；纯 `sys_admin`（无项目成员身份）尚未单独登录验证，其门禁由后端六角色接口矩阵覆盖。
